# 11. Troubleshooting and FAQs

## 11.1 Sign-in and Home

- **Cannot sign in on `/admin/login`.** That page is only for **admin@gsma.com**. Other admins use the normal **Log in** (Microsoft, Google, or credentials). Message: *You do not have permission to sign in on this page.*
- **Forgot password.** **Forgot?** → *Contact your IT administrator for password reset.*
- **Home is empty.** *No homepage destinations assigned.* Ask admin for Forms Hub and/or BI Control Tower (8.1).
- **A form disappeared.** Access is by mapping, not last season’s memory. Ask admin.

## 11.2 Forms

- **Submit blocked.** Fill Date and Shift. Distillery needs Operation Date. Power Details needs General remarks. Field Brix has many required boxes (2.9.2).
- **View only.** Banner: *View only — you can see this data but cannot submit or edit.*
- **Submitted twice.** Stop. Ask admin to remove the extra **View Data** row if policy allows.
- **HOD sent it back.** Correct and submit again (resubmit).
- **CSV vs Excel Download.** Same action. Desktop **CSV**. Phone **Excel Download**. Desktop open button is **Open Form**; phone is **Open Digital Form**.

## 11.3 Equipment and Notes

- **Cannot rename or move.** Imported/seeded cards need **locked-card manage**. Move is same-level only.
- **Production has no tree / OEM schedule.** Normal (3.4).
- **Maintenance Notes is not available.** Category is not Sugar, Engineering, Power, or Production.

## 11.4 Dashboards and upload

- **Management mill/sugar blank.** Upload **DMR workbook**, or fill DS / Operations logbooks.
- **Yard Bal. (8AM) wrong.** Check DMR 8 AM first. Logbook is only a backup at 7–8 / 8–9 AM.
- **Mill names are codes.** Upload the three Milling Operations maps (6.5).
- **Cane Quality missing in list view.** Use **Card view**. `[TO CONFIRM]`
- **Grower still says 2025.** Labels follow the uploaded file `[TO CONFIRM]`.
- **Compare % missing on Management sparklines.** Open the cell.

## 11.5 Approvals and Config

- **No Approvals menu.** You are not set as HOD (8.6–8.8).
- **Email link dead.** Forms inbox links expire after **7 days**. Use navbar **Approvals**.
- **Wrong plant on Notes.** Administrator must fix employee **category**.
