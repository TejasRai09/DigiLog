# DigiLog operator handbook and feature list

**Product:** DigiLog v2  
**Date:** 25 October 2026  
**Owner:** Plant training / DigiLog administrator `[TO CONFIRM]`  
**Audience:** Operators, chemists, maintenance, HODs, data owners, administrators, management  
**Classification:** Internal — plant operations

This book is both:

- a **how-to handbook** (numbered steps and bullets)
- a **feature list** (every live card, tab, and form)

Button names are in **English**, as on the screen. A Hindi version can be made on request.
