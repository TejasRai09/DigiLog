# 10. Daily and shift workflows

## 10.1 Start of shift (operator / chemist)

- Sign in on the employee page. Confirm there is no amber staging bar.
- **Home** → **Open Forms Hub** → your app → today’s sheet (chapter 2).
- Set **Report Date** = today and **Shift** = this shift.
- Fill readings in the units on the form.
- **Submit** → **Confirm & Commit**.
- If Forms Approval is on, tell the HOD (chapter 5). Do not submit a second copy.

### 10.1.1 Extra sheets by area

- **Mill:** also **Mill Stoppages** if the mill stopped.
- **Lab:** **Operations Logbook** and **DS Logbook** in the same shift.
- **Power:** **Power Details** needs Date and **General remarks**. Add **Stoppage Details** if a machine was down.
- **Distillery:** one **Distillery Operations Form** for the operation date.

## 10.2 Handover

- Open **View Data** for the same form.
- Confirm this shift’s row is there (or **Pending**).
- Tell the incoming shift: date, shift, stoppage, any send-back.
- **Logout**.

## 10.3 Maintenance job

- Forms Hub → Power / Sugar / Production register (chapter 3).
- Find the equipment.
- Open the discipline (Power and Sugar only).
- **Add Record** → photos → submit for HOD if approval is on.
- Short running note: navbar **Maintenance Notes** (chapter 4).

## 10.4 HOD — close the inbox

- **Approvals** (chapter 5).
- **Forms** — approve or **Send for modification**.
- **Maintenance** — history drafts for your plant.
- **Maintenance Notes** — complete or return.
- Email digest may group all three. Forms link expires in 7 days.

## 10.5 Morning management look

- **BI Control Tower** → **Management Overview**. Set **STD** or yesterday.
- Read Cane (indent, purchase, **Yard Bal. (8AM)**, Pol in Cane).
- Read Milling / Sugar. If blank, ask whether **DMR workbook** was uploaded (chapter 6).
- Crush down → **Milling Operations** → **Mill Outage**.
- Generation down → **Power Plant Operations** → **Outage**.
- Ethanol off → **Distillery Operations**.

## 10.6 Cane office morning

- **Cane Operations** — Gate 1 purchase and Gate 2 holding (>8 Hrs).
- **Centre Maturity** — low maturity %.
- **Cane Quality** — yesterday’s Brix.
- **Grower Intelligence** — only after the latest Grower Details upload.

## 10.7 Data owner after a workbook arrives

- **Data Upload** → correct tab → correct slot (chapter 6).
- Upload the plant template `[TO CONFIRM]` file names on screen.
- Open the dashboard that should change and check yesterday’s date.
