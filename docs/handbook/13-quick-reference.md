# 13. Quick reference cards

Print one page per card.

## 13.1 Operation Form

- Open: Home → **Open Forms Hub** → app → **Open Form**.
- Every shift: Date + Shift → fill → **Submit** → **Confirm & Commit**.
- View past: **View Data**. Download: **CSV**.
- Do not submit twice. Do not use view-only. Do not use staging as official.
- HOD return: correct and submit again.
- Yard/crush: Operations Logbook. Pol/Brix: DS Logbook. Mill: Mill Logbook. Power: Power Logbook. Ethanol: Distillery Operations Form. Brix: Brix Sampling Forms.

## 13.2 Equipment and Notes

- Power / Sugar: folder → equipment → discipline → **Add Record**.
- Production: **Search equipment…** → card → **Add Record**.
- Short note: **Maintenance Notes** → **Add note** (80 characters). Not for Distillery category.
- Move: same level only → **Move here**.

## 13.3 Approvals

- Tabs: **Maintenance**, **Forms**, **Maintenance Notes**.
- **Approve** or **Send for modification** (comment required).
- Notes: **Approve** or **Reject** with reason.
- Email link: 7 days.

## 13.4 Data Upload

- **Grower Intelligence:** Grower Details Season, Staff wise Bonding.
- **Management Dashboard:** Centre Indent & Purchase, DMR workbook.
- **Milling Operations:** Mill / Shredder / Lube mapping files.
- Wrong slot will not fix the dashboard.

## 13.5 Dashboards

- Whole plant → Management Overview.
- Gate / holding → Cane Operations.
- Brix → Cane Quality.
- Centres → Centre Maturity.
- Mill stops → Milling Operations.
- Generation → Power Plant Operations.
- Ethanol → Distillery Operations.
- Dishonour → Grower Intelligence.
- Dates: WTD / MTD / STD / Custom. Read **Compare**.

## 13.6 Config (admin)

- **Employees** — mapping, view-only, upload, locked cards.
- **Season Mapping** — STD windows.
- **BI Dashboards** — yield, tariff, Brix threshold.
- **Forms / History / Notes Approval** — HOD and digest times.
